1\. \[고객 관리 리스트] 화면 정의서

고객 데이터를 관리하고 작업을 시작하는 메인 화면입니다.

컴포넌트명	버튼/입력 요소	동작 및 기능 정의 (Action \& Logic)	관련 명세

헤더	서비스 로고	클릭 시 '고객 관리 리스트' 홈 화면으로 이동	-

사이드바	고객 관리	현재 화면 유지 (고객 목록 데이터 새로고침)	02

&nbsp;	AI 메일 작성	'AI 메일 작성기' 화면으로 이동	06

&nbsp;	발송 및 예약 관리	'발송 및 예약 관리' 로그 화면으로 이동	11, 12

상단 제어 바	검색창 (Input)	이름, 회사명, 이메일 키워드 입력 시 실시간 리스트 필터링	02

&nbsp;	고객 추가	클릭 시 '고객 정보 등록' 모달 팝업 오픈	01

&nbsp;	파일 불러오기	파일 탐색기 오픈. 엑셀(XLSX) 또는 CSV 선택 시 데이터를 파싱하여 리스트에 자동 추가	03

데이터 테이블	AI 메일 작성	해당 행(Row) 고객의 메모를 소스로 가지고 'AI 메일 작성기'로 이동	06

&nbsp;	수정 (아이콘)	해당 고객 정보를 수정할 수 있는 모달 팝업 오픈	05

&nbsp;	삭제 (아이콘)	확인 알럿 후 해당 고객 데이터를 DB에서 영구 삭제	05

2\. \[고객 정보 등록] 모달(Modal) 정의서

신규 고객 정보를 직접 입력하여 데이터베이스에 저장하는 인터페이스입니다.

컴포넌트명	요소	동작 및 기능 정의 (Action \& Logic)	관련 명세

입력 폼	이름/회사/직함/이메일	사용자 텍스트 입력 (이메일은 유효성 검사 포함)	01

&nbsp;	메모 (TextArea)	고객 특징 등 간단한 텍스트 입력 (AI 초안의 핵심 소스)	01

하단 액션	취소	저장하지 않고 모달 닫기	-

&nbsp;	저장하기	입력값을 DB에 기록. 성공 시 리스트 갱신 및 완료 토스트 메시지 출력	01, 04

3\. \[AI 메일 작성기] 화면 정의서

AI를 활용하여 개인화된 이메일을 생성하고 발송을 준비하는 화면입니다.

컴포넌트명	버튼/입력 요소	동작 및 기능 정의 (Action \& Logic)	관련 명세

AI 도구바	초안 생성	좌측 고객 메모를 분석하여 AI가 메일 본문(제목 포함) 자동 작성	06

&nbsp;	정중하게	작성된 본문의 내용을 유지하며 문체만 '격식 있는 비즈니스체'로 변경	07

&nbsp;	친근하게	작성된 본문의 내용을 유지하며 문체만 '부드러운 대화체'로 변경	07

&nbsp;	번역하기 (영문/기타)	선택한 언어로 본문을 번역 (비즈니스 문법 최적화 포함)	08

메일 편집기	본문 영역	AI가 생성한 내용을 사용자가 직접 수정/보완 가능	-

발송 제어	발송 예약	날짜/시간 선택 달력 오픈. 설정된 시간에 자동 발송되도록 큐에 저장	10

&nbsp;	지금 보내기	연결된 구글 SMTP를 통해 즉시 메일 발송 및 기록 생성	09, 12

4\. \[발송 및 예약 관리] 화면 정의서

발송 시스템 연결 및 예약 현황, 과거 기록을 관리하는 화면입니다.

컴포넌트명	버튼/입력 요소	동작 및 기능 정의 (Action \& Logic)	관련 명세

탭 메뉴	예약된 메일	현재 대기 중인 발송 예약 리스트 출력	11
